# Palworld Card Game · pacotes

Este repositório guarda só os pacotes instaláveis do Palworld Card Game, um projeto independente
de estudo feito em Godot. O código fica em outro repositório, privado.

O botão **Atualizar** do menu inicial do jogo consulta a última versão publicada aqui.

## Instalar

| Plataforma | Arquivo | Como instalar |
| --- | --- | --- |
| Android 7+ (arm64), tablet ou celular | `PalworldCardGame-<versão>-android.apk` | Baixe pelo aparelho, abra o arquivo e permita "instalar apps desta fonte" quando o Android pedir. Uma versão nova instala por cima e mantém baralhos e preferências. |
| Windows 10/11 (64 bits) | `PalworldCardGame-<versão>-instalador-windows.exe` | Execute o instalador. Se o Windows avisar que o editor é desconhecido, clique em **Mais informações** e **Executar assim mesmo**. |
| Windows sem instalar | `PalworldCardGame-<versão>-windows-portatil.zip` | Descompacte e abra `PalworldCardGame.exe`. |

## Direitos

Palworld, as cartas e as artes pertencem à Pocketpair e à Bushiroad. Este é um projeto de estudo
sem fins comerciais e sem vínculo com elas.
